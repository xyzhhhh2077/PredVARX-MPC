# copyZfix 方案说明

## 两个副本的对比

### 副本 C（累积重辨识基线）
- **重辨识策略**：每 Nr=50 步，用**全部历史数据** (yc, uc) 重辨识
- **Pbar 更新**：❌ 不更新（固定用初始 Pbar0）
- **滑动窗口**：❌ 无（数据只增不减）
- **作用**：作为基线对照，验证滑动窗口 + Pbar 同步更新的改进效果

### 副本 Zfix（滑动窗口 + Pbar 同步更新 + Z2 非对称 soft）
- **重辨识策略**：每 Nr=50 步，用**滑动窗口数据**（离线 + 最近 win_keep=250 步）重辨识
- **Pbar 更新**：✅ 每次重辨识后 `PbrS = null(Pk')` 同步更新
- **滑动窗口**：✅ 窗口大小 win_keep=250，避免旧数据拖累
- **Z2 非对称 soft 约束**：
  - 当 `y2 + σ > y_max` 时，施加 soft 惩罚
  - `soft = max(0, min(y2 + σ - y_max, σ))`
  - 将 soft 加到参考信号上，引导 MPC 主动收缩

### 两个副本的共同点
- **辨识算法**：predvarx_identify（IVR + OLS u-stripping + VARX）
- **MPC**：标准 QP，Q = I_ℓ (前 ℓ=2 通道), R = 2I_m
- **噪声自适应**：滑动窗口估计 σ_ε (DLV) 和 σ_ē (static)
- **参考信号**：分段常数，每 400 步切换

## 为什么只跟踪 y2？

### 数学原因

MPC 的代价函数：
$$J = \sum_{j=0}^{N-1} \|\mu_y(j) - r_j\|_Q^2 + \|c_j\|_R^2$$

其中 Q 矩阵只惩罚前 ℓ=2 个输出通道：
```matlab
Q = zeros(p); Q(1:ell, 1:ell) = eye(ell);  % p=15, ℓ=2
```

MPC 预测：`μ_y(j) = P̂ · x̂(j)`，其中 `P̂ ∈ R^{p×ℓ}` 是 IVR 估计的子空间。

**关键**：`P̂` 的列向量在 y₂ 方向分量大，在 y₁ 方向分量小。

几何解释：
- `span(P̂)` 是 R^15 中的一个 2 维平面
- 这个平面与 y₂ 轴夹角小 → 投影分量大 → MPC 在此方向有强控制效果
- 这个平面与 y₁ 轴夹角大 → 投影分量小 → MPC 几乎不影响 y₁

### 为什么 Q 惩罚 y(1), y(2) 但只 y2 跟踪上了？

因为 Q 惩罚的是 **观测空间的前 2 个坐标方向**，但 MPC 实际控制的是 **降维子空间 span(P̂)**。

`P̂` 的第一列（对应 y(1) 方向）在 y₁ 轴的分量很小，所以即使 Q 惩罚了 y(1) 方向的误差，MPC 也无法通过控制 x̂ 来显著改变 y₁。

**类比**：一个 2 维平面斜穿 3 维空间。平面与 y₂ 轴几乎平行，与 y₁ 轴几乎垂直。在平面上移动，y₂ 变化大，y₁ 几乎不变。

### 解决方案（未实施）
1. **增大 ℓ**：ℓ=n=6 时 P̂ 覆盖全空间，所有输出通道都可跟踪
2. **调整 Q 方向**：让 Q 惩罚的方向对齐 P̂ 的列空间（需要先估计 P̂）
3. **Procrustes 对齐**：已知参考投影矩阵，旋转 P̂ 使对齐目标方向

## 仿真参数

| 参数 | 值 | 说明 |
|:--|:--|:--|
| n, m, p | 6, 3, 15 | 状态/控制/观测维度 |
| ℓ | 2 | 降维维度 |
| T_off | 200 | 离线数据 |
| T_cl | 2000 | 闭环测试 |
| N_pred | 30 | MPC 预测步长 |
| Nr | 50 | 重辨识间隔 |
| win_keep | 250 | 滑动窗口大小 |
| nf | [1,1.5,0.8,2,0.5,...] | 噪声变化因子 |
| ni | 400 | 噪声段长 |
| y_max | 3.10 | 约束上界 |
