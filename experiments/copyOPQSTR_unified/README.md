# copyHKOPQSTR_unified：按 Obsidian 定义还原的统一参数对比

## 目的

旧实验和现行 Git 曾重复使用 H/K/O/P/Q/S/T/R 字母，但 plant、维数、噪声、时域和 MPC 口径不同，历史 MAE 不能直接比较。本目录不覆盖任何已有副本，而是使用一套统一的 copyX-family 参数，只保留 Obsidian 笔记中每个字母代表的算法差异。H/K 原先只有历史说明或旧参数源码，本次已经补入统一参数可执行源码。

统一参数：

```text
seed=20260710
n=6, m=3, p=30, ell=5, tracked=[1 2]
T_off=1500, T_cl=1200, N=18
u in [-3,3], y_max=2.00, alpha_joint=0.10
Q(y1,y2)=80, Ru=0.18 I
smooth sigma_w=[0.020,0.090], sigma_e=[0.025,0.100]
```

所有方法使用同一 plant、离线数据、参考、标准正态噪声样本、SMPC、在线协方差窗口和 fallback 规则。

## 还原定义

| 方法 | Obsidian/历史差异的统一实现 |
|---|---|
| H | 以 Q 的控制感知结构为初值；每 300 步只用最近 300 步闭环数据滑动窗口重辨识完整 $A,B,P,R$；滚动更新协方差；无偏差修正。 |
| K | 以 Q 的控制感知结构为初值；每 300 步用离线数据与截至当前的全部闭环数据累积重辨识；50 步 Dinkla 创新协方差；EMA 输出偏差修正，$\gamma=0.02$。 |
| O | 自由白化 IVR + 斜投影双基和 SVD 对齐；不保证 tracked coverage。 |
| P | 中心化全局 PCA/SVD 正交子空间 + VARX。 |
| Q | 固定 tracked axes，在其正交补中做迭代 IVR；正交 $R=P$。 |
| R | 满秩一阶白化 IVR + 直接反白化；不加 tracked constraint。不是完整 Algorithm 1。 |
| S | 以 Q 为初值，每 30 步用离线集 + 最近 100 步在线数据重新辨识 $A,B,P,R$；预测模型随结构同步刷新。 |
| T | 与 Q 相同的固定控制感知结构，在线只更新创新/观测残差协方差，不重辨识结构。 |

这里的 H/K/S/T 还原重点是区分“滑动窗口结构重辨识”“累积结构重辨识 + 偏差修正”“离线集 + 最近数据重辨识”和“仅在线不确定性更新”。它不复刻旧版本的负分位数、坐标不一致、差分目标或分段预测时域，因为用户要求 plant、控制器和评价参数统一，只保留方法本身的辨识/适应差异。

## 源码组成

- `copyOPQSTR_common_config.m`：唯一统一参数入口；
- `copyOPQSTR_generate_common_data.m`：一次生成共享 plant、离线数据、参考和噪声；
- `copyOPQSTR_build_models.m`：定义 H/K/O/P/Q/R/S/T 的结构与在线策略；
- `run_copyOPQSTR_case.m`：统一闭环、协方差、重辨识、偏差修正和指标计算；
- `copyOPQSTR_unified.m`：八种方法的公平对比入口；
- `tests/test_copyOPQSTR_unified.m`：结构与策略回归测试。

共享 SMPC 每拍根据当前 `model.A/B/P/R` 现场重建预测矩阵。因此 H/K/S 每次重辨识后，名义预测立即使用新模型，不会出现“协方差更新了，但 $M_j/N_j$ 仍是旧模型”的问题。

## 实测结果

本轮已真实执行 MATLAB 结构测试和八方法闭环。权威原始数据位于 `results/copyOPQSTR_unified_metrics.csv`。

| 方法 | MAE y1/y2 | RMSE y1/y2 | prediction RMSE | coverage error | QP成功率 | fallback | 重辨识次数 |
|---|---:|---:|---:|---:|---:|---:|---:|
| H | 0.3577 / 0.1946 | 0.5650 / 0.2663 | 0.2227 | 0 | 82.25% | 213 | 4 |
| K | 0.0905 / 0.0964 | 0.1300 / 0.1368 | 0.0987 | 0 | 100% | 0 | 4 |
| O | 0.9685 / 1.1231 | 1.1505 / 1.2111 | 0.2842 | 1.9038 | 13.00% | 1044 | 0 |
| P | 0.0770 / 0.0788 | 0.1082 / 0.1086 | 0.0948 | 1.2995 | 100% | 0 | 0 |
| Q | 0.0917 / 0.0947 | 0.1335 / 0.1347 | 0.0995 | 0 | 100% | 0 | 0 |
| R | 0.4451 / 0.7320 | 0.6136 / 0.9821 | 0.1473 | 1.6327 | 43.92% | 673 | 0 |
| S | 0.0807 / 0.0801 | 0.1115 / 0.1130 | 0.0990 | 0（初始结构） | 100% | 0 | 40 |
| T | 0.0917 / 0.0947 | 0.1335 / 0.1347 | 0.0995 | 0 | 100% | 0 | 0 |

解释边界：

- H 的纯闭环滑动窗口只有 300 个样本，四次重辨识后出现 213 次 fallback；这说明统一控制器下的短窗结构重辨识并不稳健，不能把旧 H 的“QP 0/1200”直接迁移到新 plant。
- K 的累积数据重辨识 + 50 步创新协方差 + EMA 偏差修正在该固定种子下保持 100% QP 可行，数值接近 Q/T，但这只是一次统一参数实验，不是一般优越性证明。
- P 虽然没有显式控制覆盖且 coverage error 为 1.2995，但在这个特定 plant/参考上仍然闭环可行并得到最低静态 MAE；这不能提升为一般控制保证。
- Q/T 给出结构上的精确覆盖。S 通过高频在线重辨识改善 MAE，但出现很小的经验越界率（y1 0.1667%，y2 0.0833%），因此不能只按 MAE 判断优越性。

## 理论边界

- O/R 的双基误差接近机器精度，只证明几何一致，不证明控制覆盖。
- R 是满秩 $s=1$ 白化消融，不是完整 Mo–Qin Algorithm 1。
- H/K/S 的在线重辨识重新构造完整 `model.A/B/P/R`；共享 SMPC 每次调用都由当前模型现场构造 $M_j,G_j$，因此不存在更新结构却继续使用旧预测矩阵的问题。
- T/Q 数值相同是预期结果：二者都固定 Q 的结构并使用同一在线协方差更新；T 的作用是显式标记“只更新不确定性”。
- 本实验是统一参数的算法消融，不取代各历史版本在原参数下的考古记录。
