# copyOPQSTR_unified：按 Obsidian 定义还原的统一参数对比

## 目的

旧实验和现行 Git 曾重复使用 O/P/Q/S/T/R 字母，但 plant、维数、噪声、时域和 MPC 口径不同，历史 MAE 不能直接比较。本目录不覆盖任何已有副本，而是使用一套统一的 copyX-family 参数，只保留 Obsidian 笔记中每个字母代表的算法差异。

统一参数：

```text
seed=20260710
n=6, m=3, p=30, ell=5, tracked=[1 2]
T_off=1500, T_cl=1200, N=18
u in [-3,3], y_max=2.00, alpha_joint=0.10
Q(y1,y2)=80, Ru=0.18 I
smooth sigma_w=[0.020,0.090], sigma_e=[0.025,0.100]
```

所有方法使用同一 plant、离线数据、参考、标准正态噪声样本、SMPC、在线协方差窗口和 fallback 规则。

## 还原定义

| 方法 | Obsidian/历史差异的统一实现 |
|---|---|
| O | 自由白化 IVR + 斜投影双基和 SVD 对齐；不保证 tracked coverage。 |
| P | 中心化全局 PCA/SVD 正交子空间 + VARX。 |
| Q | 固定 tracked axes，在其正交补中做迭代 IVR；正交 $R=P$。 |
| R | 满秩一阶白化 IVR + 直接反白化；不加 tracked constraint。不是完整 Algorithm 1。 |
| S | 以 Q 为初值，每 30 步用离线集 + 最近 100 步在线数据重新辨识 $A,B,P,R$；预测模型随结构同步刷新。 |
| T | 与 Q 相同的固定控制感知结构，在线只更新创新/观测残差协方差，不重辨识结构。 |

这里的 S/T 还原重点是 Obsidian 中“在线结构重辨识”与“仅在线不确定性更新”的差异。它不复刻旧 S 的负分位数或坐标不一致 bug，因为用户要求参数和现有正确控制器统一。

## 实测结果

| 方法 | MAE y1/y2 | RMSE y1/y2 | prediction RMSE | coverage error | QP成功率 | fallback | 重辨识次数 |
|---|---:|---:|---:|---:|---:|---:|---:|
| O | 0.9685 / 1.1231 | 1.1505 / 1.2111 | 0.2842 | 1.9038 | 13.00% | 1044 | 0 |
| P | 0.0770 / 0.0788 | 0.1082 / 0.1086 | 0.0948 | 1.2995 | 100% | 0 | 0 |
| Q | 0.0917 / 0.0947 | 0.1335 / 0.1347 | 0.0995 | 0 | 100% | 0 | 0 |
| R | 0.4451 / 0.7320 | 0.6136 / 0.9821 | 0.1473 | 1.6327 | 43.92% | 673 | 0 |
| S | 0.0807 / 0.0801 | 0.1115 / 0.1130 | 0.0990 | 0（初始结构） | 100% | 0 | 40 |
| T | 0.0917 / 0.0947 | 0.1335 / 0.1347 | 0.0995 | 0 | 100% | 0 | 0 |

注意：P 虽然没有显式控制覆盖且 coverage error 为 1.2995，但在这个特定 plant/参考上仍然闭环可行并得到最低静态 MAE；这不能提升为一般控制保证。Q/T 给出结构上的精确覆盖。S 在该固定种子中通过在线重辨识改善 MAE，但出现很小的经验越界率（y1 0.1667%，y2 0.0833%），因此不能只按 MAE 判断优越性。

## 理论边界

- O/R 的双基误差接近机器精度，只证明几何一致，不证明控制覆盖。
- R 是满秩 $s=1$ 白化消融，不是完整 Mo–Qin Algorithm 1。
- S 的在线重辨识重新构造完整 `model.A/B/P/R`；共享 SMPC 每次调用都由当前模型现场构造 $M_j,G_j$，因此不存在更新结构却继续使用旧预测矩阵的问题。
- T/Q 数值相同是预期结果：二者都固定 Q 的结构并使用同一在线协方差更新；T 的作用是显式标记“只更新不确定性”。
- 本实验是统一参数的算法消融，不取代各历史版本在原参数下的考古记录。
