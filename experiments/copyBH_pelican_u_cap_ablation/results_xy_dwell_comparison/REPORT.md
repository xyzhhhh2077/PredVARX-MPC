# copyBH input-cap ablation — sustained x/y face report

## Scope

This is an **experimental input-cap ablation only**. The parent copyBG theory,
identified model, covariance propagation, physical-wind injection, SMPC chance
constraints, horizon, weights, seeds, and QP controller are unchanged.

Compared standardized motor-command boxes:

- `[-6, 6]`
- `[-6.5, 6.5]`
- `[-7, 7]`

## Fair experiment

All runs used:

- 12,000 samples (`120 s`)
- the same center initial state and initial command
- the same `xy-face-dwell` reference
- the same innovation realization and physical-wind realization
- the same stage tightening and stage mean bounds

The reference was:

`center -> x=3.57 (hold 24 s) -> center -> y=3.57 (hold 24 s) -> center`

The hard bound was `3.9124117280`; the near-hard threshold was
`3.5124117280`. Each axis had 2,851 target-window samples at or above that
threshold (including the near-target parts of the smooth ramps).

The comparison script hashed the reference, initial state, initial command,
innovation, wind, stage tightening, and stage mean bounds. Every hash was
identical across the three runs.

## Conclusion

Relaxing the cap produced a real, monotonic empirical improvement:

- less input saturation;
- higher x/y mean task values during the near-hard target windows;
- more near-hard samples;
- slightly longer contiguous near-hard segments.

However, `±7` did **not** produce sustained 24-second x/y near-hard tracking.
The longest continuous segments were only `3.02 s` for x and `3.95 s` for y.
Therefore the correct conclusion is:

> `±7` is the best tested modest relaxation, but relaxing the input box alone is
> insufficient for long-duration x/y near-hard tracking under the unchanged
> SMPC algorithm and chance constraints.

This is an experiment result, not a new theorem, controller, or safety claim.
