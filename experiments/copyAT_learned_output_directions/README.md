# copyAT：同一旧数据下学习输出方向

## 目的

比较三种二维输出锚：

1. **fixed**：CRTE 当前人为固定的物理输出 `y1,y2`；
2. **supervised**：给定任务输出标签后，从同一旧数据的输出协方差度量中恢复该任务子空间；
3. **authority**：不使用任务通道标签，仅从同一旧 `(u,y)` 数据拟合输出 VARX，并按有限时域输入响应能量学习最容易被输入推动、同时在输出中可见的方向。

## 公平性

- 离线训练集直接读取 copyAR 已生成的 `y_off,u_off`，不生成新训练轨迹；
- plant、参考、SMPC 权重、约束和预测时域沿用 copyAR；
- 当前提交运行前 300 步同种子 smoke 比较，避免把长网格计算包装成已完成验证；
- fixed 与 supervised 在监督法恢复同一任务平面后，共用 copyAR 已验证辨识模型，隔离“方向变化”本身；
- authority 分支仅替换学习锚并重建对应双基模型；
- 三个分支使用完全相同的闭环过程噪声与测量噪声样本；
- `new_training_samples = 0`；闭环运行只用于公平测试，不回灌训练。

## 数学对象

可达分支先用旧数据拟合

```text
y(k+1) = Ay y(k) + By u(k) + e(k)
```

构造有限时域输入权威矩阵

```text
Wy = sum_{h=0}^{H-1} Ay^h By Ru^{-1} By' (Ay^h)'
```

再解 `Wy e = lambda Cy e`，选择最大特征值方向。该方法学的是输入最能推动的输出组合，不保证等于任务所需的 `y1,y2`。

监督分支恢复任务标签所声明的输出子空间；它用于检验“学习能否得到同一方向”，不声称发现了优于人工选择的新任务。

## 边界

这是 CRTE 之外的实验扩展。一次同种子闭环比较不能证明全局最优、稳定性、递归可行性或跨工况泛化。
